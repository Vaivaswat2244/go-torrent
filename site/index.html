A BitTorrent client,
from the wire up.

go-torrent is a BitTorrent client written in Go, with a terminal UI. Everything below the interface is implemented from scratch: bencode, .torrent parsing, HTTP and UDP trackers, the peer wire protocol, DHT peer discovery, and MSE protocol encryption.

go install github.com/Vaivaswat2244/go-torrent/cmd/client@latest

what it does

  • .torrent files, single- and multi-file, and magnet links with metadata fetched from peers
  • HTTP/HTTPS and UDP trackers, with periodic re-announce, plus DHT peer discovery
  • Uploading and seeding, with the standard choke algorithm: four unchoke slots recomputed every 10s and an optimistic unchoke every 30s
  • Resume: existing data is re-hashed on start, and valid pieces are skipped
  • Terminal UI with progress, transfer rates, ETA, ratio, and a live event log

works on networks that block BitTorrent

Some networks, campuses and workplaces especially, reset any connection that looks like BitTorrent. go-torrent supports Message Stream Encryption, the obfuscated handshake mainstream clients use, and it is on by default: connections are encrypted where the peer supports it and fall back to plain BitTorrent otherwise. If downloads work elsewhere but not on one network, run with -encryption require.

MSE hides BitTorrent from filters; it is not privacy. Your IP address is visible to every peer and tracker as usual.

what it doesn't do

No UPnP or NAT-PMP, so behind a router you forward the port yourself. No PEX, no rarest-first or endgame piece selection, no rate limiting, one torrent at a time, no IPv6. The full list is in the docs; what is implemented is tested, including a seeder and leecher run against each other over loopback under every encryption setting.

get started

Install with the Go toolchain, point it at a torrent file or magnet link, and it downloads, then stays up and seeds until you quit or hit a ratio or time limit.
